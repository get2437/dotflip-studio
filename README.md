# DOTFLIP Studio

画像をドット絵に変換し、ピクセルを編集し、コマを重ねてアニメーションを作るブラウザアプリです。日本語UI。Codexなどのコンピュータユーズからも操作できます。

Pixel art and frame animation editor that runs in your browser. Import images or sprite sheets, edit pixels, and export looping GIFs. All image processing runs locally in the browser; no API key is required.

**[Web版を開く — DOTFLIP Studio](https://imadokimatome.com/tools/dotflip/)** · [GitHub Pages版](https://get2437.github.io/dotflip-studio/) · [ダウンロード版](https://github.com/get2437/dotflip-studio/releases/latest)

![SURF STRIKE — DOTFLIPで作成した残像なしの戦闘アニメーション](docs/surf-strike.gif)

サンプルのキャラクター画像はAI生成です。開発にもAIを使用しています。画像の出自と利用条件は [ASSETS.md](ASSETS.md)、コードと同梱素材のライセンスは [LICENSE](LICENSE)、外部ライブラリの表示は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

## ブラウザですぐ使う

[いまどきまとめのWeb版](https://imadokimatome.com/tools/dotflip/)または[GitHub Pages版](https://get2437.github.io/dotflip-studio/)をChrome / Edgeなどの新しいブラウザで開くだけで使えます。Node.jsのインストール、GitHubへのログイン、APIキーは不要です。

「サンプル（64コマ）」で再生・編集を試すか、自分の画像を読み込んでドット絵とアニメーションを作成してください。GIFやPNG、プロジェクトJSONは手元の端末にダウンロードできます。

読み込んだ画像の処理と自動保存はブラウザ内で行います。自動保存は開いたURLとブラウザにひもづくため、別の端末へ移す場合やバックアップには「保存」でプロジェクトJSONを持ち出してください。

## ダウンロードしてローカルで使う

1. [Releases](https://github.com/get2437/dotflip-studio/releases/latest) から `dotflip-studio-v1.0.0.zip` をダウンロードして展開します。
2. [Node.js](https://nodejs.org/) 22以降を用意します。
3. Windowsでは展開したフォルダの `start-studio.cmd` を実行します。macOS / Linuxでは、そのフォルダで `npm start` を実行します。
4. 表示された `http://127.0.0.1:4173` をブラウザで開きます。終了するにはターミナルで `Ctrl+C` を押します。

リリースZIPにはビルド済みの `dist/` が含まれます。ZIPからの起動では `npm ci` や外部通信は不要です。Chrome / Edgeなどの新しいブラウザを使用してください。

## ソースからローカルで起動

ローカル起動と開発にはNode.js 22以降を使用します。Web版の利用には不要です。

```sh
git clone https://github.com/get2437/dotflip-studio.git
cd dotflip-studio
npm ci
npm run build
npm start
```

表示された `http://127.0.0.1:4173` を開きます。Windowsでは `start-studio.cmd` も使えます。`dist/` を静的HTTPサーバーで配信するだけで動き、画像処理用のバックエンド、APIキー、CDNは不要です。`file://` で直接開く方法はES modules / Workerの制約があるため使用しません。

## スマホで使う

画面下の「画像」「編集」「動き」で作業画面を切り替えます。変換後やプロジェクトを開いた後は「編集」に移ります。上部の「保存」「書き出し」はどの画面からも使えます。

- **画像**：画像を選び、サイズと色数を決めて変換します。「動き」の「サンプル（64コマ）」から完成アニメーションを開けます。
- **編集**：ツールを選んでタップ・ドラッグ。「描画色」を開くと色を選べます。＋／−で拡大縮小し、「画面移動」でドラッグすると描かずに表示位置を動かせます。FITは絵全体の表示に戻します。
- **コマ操作**：編集画面を下へスクロールし、コマの列を横にスワイプ。複製・並べ替え・表示時間を調整できます。
- **動き**：プレビュー、まばたきや揺れの下地、アクション演出を操作します。スマホではGIFの初期出力倍率を2倍にしています。

ファイルの保存先はブラウザやOSのダウンロード設定に従います。端末を移るときは `.dotflip.json` を保存し、移動先で「開く」から読み込んでください。

## AIにはどう指示する？

元画像をAIのチャットに添付し、**残す特徴・サイズや色数・動かす部分・ループの長さ・保存形式**を伝えてください。画面上部の「AI用手順」に、素材生成→4×4のシート分割→16コマの確認→戦闘作成→再生確認→透過GIF保存の操作順、確認条件と失敗時の戻り先をまとめています。「動き」画面からも同じ手順を開けます。[手順を直接開く](https://get2437.github.io/dotflip-studio/#ai-guide)こともでき、手順内の「AI指示例」から3つの例をコピーできます。

たとえば、まばたきと髪の揺れなら次のように頼めます。

> 添付画像をDOTFLIP Studio（https://get2437.github.io/dotflip-studio/）のコンピュータユーズで、動くドット絵にしてください。顔・髪型・服を保ち、128×128px、24〜32色を目安に輪郭を手直し。自然なまばたきと髪が1〜2px揺れる動きをつけ、2〜3秒のループにしてください。顔とカメラは固定、残像なし。再生でちらつきと最初・最後のつながりを確認し、2倍GIFと編集可能な.dotflip.jsonを保存してください。

激しい動きには、同じキャラクターの連続ポーズが必要です。「透明背景の16ポーズを4×4に並べ、各ポーズを離す」「同じ縮尺と足元にそろえる」「ビーム・残像オフ、全力コンボ」「元のポーズと完成版の両方を保存」と指定すると進めやすくなります。

この指示は画像生成やコンピュータユーズに対応したAIに渡すものです。DOTFLIP自体はAIモデルを内蔵していません。使うAI環境で対応している機能を確認してください。

## 主な操作

1. PNG / JPG / WebP / BMPを読み込みます。複数ファイルは自然順（01, 02, 10）で読み込まれます。1枚のスプライトシートは「シート分割」で等分グリッドに分割できます。
2. サイズ（1〜256px）、色数、パレット、ディザ、縮小方式を決め、「ドット絵に変換」。縦横の比率は「全体を収める」「中央で切り抜く」「サイズに合わせる」から選べます。
3. 鉛筆、消しゴム、塗りつぶし、スポイト、直線、四角形で手直しします。目のアイコン（T）で元画像を下絵として透かせます。範囲選択後は1px移動、左右反転、Deleteで範囲消去できます。
4. コマを複製・追加・並べ替え、オニオンスキンで前コマと比較します。各コマの表示時間は20〜5000ms。最大64コマ。
5. 「動き」で上下移動、弾み、選択部分の左右移動、まばたきのコマを追加できます。まばたきは目を囲み、周囲の肌や毛と同じまぶたの色を指定します。
6. GIF、スプライトシートPNG＋座標・時間のJSONをまとめたZIP、単一コマPNGに書き出します。倍率は1/2/4/8倍、ニアレストで輪郭を維持。GIFはループ再生し、時間は10ms単位に丸めます。
7. 「保存」で `.dotflip.json` を持ち出し、「開く」で復元します。

## AIと協働する

### 連続ポーズから戦闘シーンを作る

透過背景のポーズを2〜16コマ用意し、「動き」→「戦闘シーン」を開きます。16コマなら、構え・予備動作・ストレート・クロス・アッパー・踏み込み・ジャンプ・空中蹴り・回転蹴り・急降下・着地・回避・溜め・放出・反動・構えの順に並べると演出に合います。

「サンプル（64コマ）」から、金髪の成人女性の戦闘ループを再生・編集できます。画像生成で作ったポーズを実際のUIから切り出し、変換・演出・書き出しした作品です。全コマのPNGシートと時間情報を軽量なサンプルとして同梱しています。

強さと海辺／夜のステージを選び、「斬撃エフェクト」「ビーム」「残像」「画面揺れ」の文字付きチェックボックスで演出を指定します。ビームと残像は標準でオフです。256×176px・64コマ・3.12秒に展開し、キャラクターは透過レイヤーで編集します。背景・訓練ドローン・演出は別レイヤーでプレビューに表示します。GIF・PNG・シートは標準でキャラクターのみを書き出し、背景は透過です。シーン全体が必要な場合は書き出し画面で「背景・敵を含める」にチェックします。レイヤーはプロジェクトJSONにも保存され、コマの複製・並べ替え・Undoでも保持します。元のポーズは作成前に保存しておくと再利用できます。

AI製のスプライトシートで手足が等分線を越えるときは、シート分割の「透過領域を抽出」を選びます。アルファ128以上でつながる主要な塊を検出し、孤立した小さなごみを除いて、同じ縮尺・中央・足元基準にそろえます。背景が透明で、各キャラクターが離れている画像が必要です。接触したキャラクターを分離する機能はありません。等分グリッドでは画像サイズが割り切れなくても、全画素を隙間なく分割します。

このアプリはモデルを呼び出しません。GPT-6.1 Sol等のコンピュータユーズが外側から画面を操作するための作業環境です。画像の意味を解釈する作画はコンピュータユーズ側で行い、アプリは正確なグリッド、減色、編集、コマ管理、出力を担当します。詳しい操作方針は `COMPUTER_USE_GUIDE.md` にあります。

自動変換は縮小・減色による下地作りです。意味を理解して新しいポーズを描き起こす生成AI、人物・髪・服の自動セグメント分割、完全な背景切り抜きは内蔵していません。選択部分の移動では元の位置が透明になるため、必要に応じて下地を描き足してください。ソースは透過か単色背景、キャラクターの周囲に余白があると扱いやすくなります。

## 保存とプライバシー

- 読み込んだ画像と作業データはブラウザで処理します。アプリのコードにアップロード処理・外部モデル呼び出し・解析トラッカーはありません。
- 作業は同じブラウザ・同じオリジンのIndexedDBに自動保存します。別のURL・ブラウザ・端末とは同期しません。
- 複数画像を読み込んだとき、自動復元用の元画像は最初の1枚のみ保管します。変換後の全コマは復元されます。元の連番を再変換する場合は再度読み込んでください。
- プロジェクトJSONにはコマ、サイズ、色、時間と、アクションの任意の背景レイヤーを保存します。変換前の元画像は含まれません。
- ブラウザのデータ消去や容量不足に備え、保存ボタンでファイルを持ち出してください。
- Undoは最大30履歴、約48MBを目安に制限。大きい作品では履歴件数が減ります。

## 開発・検証

```powershell
npm run build
npm test
npm run release:package
```

`release:package` はビルド済みの `dist/` を含む配布ZIPとSHA-256チェックサムを `release/` に作成します。リポジトリには個人のサイトID・認証情報・作業画像・自動保存データを含めません。ビルドした `dist/` は任意の静的HTTPサーバーで配信できます。

`main`への更新はGitHub ActionsでWindows / Linuxのテストを通過した後、ビルド済みの`dist/`をGitHub Pagesに自動公開します。プルリクエストではテストのみ実行します。

`app/core.js` がDOMから独立した画像処理・コマ操作・JSON検証、`app/action.js` が透過スプライト抽出・戦闘シーン合成、`app/app.js` がUI、`app/export.js` がGIFとシート定義、`app/gif-worker.js` がGIFのバックグラウンド生成を担当します。色は全コマ共通のパレットで量子化し、アニメーション中の色のちらつきを抑えます。透明色と不透明の黒は別のGIFインデックスです。

GIF回帰試験は `artifacts/demo.gif` と元プロジェクトを出力します。検証方法は [QA.md](QA.md)、変更への参加方法は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。
