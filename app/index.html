AI用手順

元画像から乱舞の透過GIFを作る手順。ポーズの描き起こしはAI側の画像生成を使い、変換後のピクセル修正・全コマの確認・保存まで、AIがこのサイトをコンピュータユーズで操作します。

スマホ幅では下の「画像」「編集」「動き」で切り替えます。16コマの透過ポーズが用意できている場合は2から始めます。

  1. 16ポーズの素材を用意

    元画像をデザイン参照にして、同じキャラクターの16ポーズを生成します。通常のイラストから作れるので、この段階でドット絵になっている必要はありません。ドット絵化は2の専用変換エンジンで行います。

    透明背景のPNGに4列×4行、左上から横順に1体ずつ配置。顔・髪・服・武器・縮尺をそろえ、手足と武器が切れない余白を取ります。輪郭と細い武器が識別できる大きさで用意します。

    順序：01構え → 02予備動作 → 03初撃 → 04逆方向の一撃 → 05上への攻撃 → 06踏み込み → 07跳躍 → 08空中攻撃 → 09回転攻撃 → 10振り下ろし → 11着地 → 12回避 → 13大技の予備動作 → 14振り抜き → 15復帰 → 16最初と同じ構え。武器は元画像に合わせます。

    確認：16体が離れていること。背景・敵・文字・ビーム・残像・斬撃などの演出を描き込まず、実際に透明なPNGであること。

  2. 画像を読み込み・分割

    「画像」→「画像を開く」で生成したPNGを読み込みます。「シート分割」を開き、「分割して読み込む」をオン。列＝4、行＝4、コマ数＝16、切り出し方＝「透過領域を抽出」にします。

    変換エンジン＝「ドット絵化（輪郭・陰影）」、サイズ＝64×64、色数＝24、パレット＝「元画像から自動」、ディザリング＝「なし」。「変換設定」のドット絵化の強さ＝「標準」、画像の収め方＝「全体を収める」を選び、「ドット絵に変換」を押します。

    専用エンジンが縮小前に面と陰影を整理し、縮小後に孤立点と輪郭を補正します。すでにドットで作画した素材を保つときは「縮小・減色のみ」と「ニアレスト」を使います。エンジンはPixel-Art Converterの処理を組み込んだもので、このブラウザ内で動きます。

    確認：「編集」のコマ数が16 FRAMESになり、各コマに1体だけ表示されること。複数のPNGを読み込む場合は01〜16の名前順に用意し、「分割して読み込む」をオフにします。

  3. AIが16コマのピクセルを修正・保存

    「編集」で全コマを順に選び、元画像と見比べます。AI自身が目・顔・髪・衣装・剣の潰れ、輪郭の孤立点や穴を見つけ、鉛筆・消しゴム・直線などで描き直します。修正作業を利用者へ渡さず、各コマで必要なピクセルを実際に編集してください。

    精密な修正は「座標編集」を開き、X・Yを入れて「表示」。数字付き拡大図と現在の色を見て、描画色を#RRGGBBで指定し「1px描く」か「1px消す」。左上が0,0です。拡大図のクリックでも座標を指定でき、誤った変更は「元に戻す」で戻せます。目や剣先を描く前に、そのコマの向き・顔の範囲・武器の線を確認します。

    同じ特徴を全コマで保ち、最初と最後の構えをそろえます。修正前後を拡大と通常サイズで見比べ、必要なら「書き出し」→4×→「PNG 現在のコマ」でも確認します。

    プロジェクト名を「キャラ名-poses」などに入力し、欄外をクリックして確定。「保存」で元の16ポーズを.dotflip.jsonとして保存します。

    確認：全16コマを見て、AIが必要な箇所を修正済みであること。目・剣・輪郭が通常サイズでも読め、修正で別の部位を壊していないことを確認してから、元のPNGと修正した16コマのJSONを保存します。

  4. 戦闘シーンを作成

    「動き」→「戦闘シーン」。強さ＝「全力コンボ」、ステージ＝好みで選択。「斬撃エフェクト」はオン、「ビーム」と「残像」はオフ。「画面揺れ」は希望に合わせ、「戦闘シーンを作成」を押します。

    確認：64 FRAMES、3.12秒になること。キャラクターは透過で編集でき、背景・敵・斬撃などのシーン演出はプレビュー用の別レイヤーにあること。

  5. 再生して仕上げ

    「動き」の再生ボタンで1周以上確認します。手足・武器の欠け、顔や色のちらつき、不要な残像、最初と最後のつながりを確認し、気になるコマを「編集」で直します。

    打撃の間を保つため「FPS」は変更せず、必要なコマの「表示時間」で調整します。完成版は元データと別のプロジェクト名にし、欄外で確定して「保存」します。

  6. 透過GIFを書き出し・確認

    上の「書き出し」→出力倍率＝2×、背景＝「透過」、「背景・敵を含める」＝オフを確認し、「GIF アニメーション」を押します。2×は512×352px、4×は1024×704pxです。

    完了条件：保存したGIFを開いて再生できること。輪郭・陰影・色のまとまりがドット絵として仕上がり、キャラクターだけが透明背景で動くこと。背景・敵・ビーム・残像が入らず、ループに欠けやちらつきがないこと。GIFが保存できたことと、ドット絵の作画ができたことを別々に確認し、元の16ポーズと完成版のJSON、GIFを渡します。

    JSONは編集用データで、「開く」から編集を再開できます。GIFを使うだけならJSONの操作は不要です。元画像はJSONに含まれません。

止まったとき

縮小したイラストに見える
変換エンジンを「ドット絵化（輪郭・陰影）」にし、強さを「強め」にして再変換。顔や剣が潰れる場合は「弱め」、サイズ96×96、32色を試します。出力倍率を上げるだけでは作画は変わりません。
画像生成が使えない
16コマの透過ポーズを用意して2から進めます。元画像1枚のまま、乱舞の作成はできません。
検出数が違う・ポーズが混ざる
4×4のセル内に収まっている素材なら、切り出し方を「等分グリッド」にして再変換。体や武器が接触・はみ出しを起こしていたら、1へ戻り余白を増やして生成し直します。
透過背景・2〜16コマのエラー
16ポーズのJSONを「開く」から読み直します。64コマの完成版を戦闘素材にしないこと。背景が焼き込まれていたら1へ戻ります。単色背景だけは「変換設定」→「単色の背景を透過」で除去できます。
GIFに背景やビームが残る
「背景・敵を含める」をオフ、背景を「透過」にして再出力。素材の時点で描かれたビームや背景はチェック項目では消せないので、元ポーズを修正します。
GIFが大きすぎる・保存に失敗
出力倍率を2×か1×に下げて再出力します。
